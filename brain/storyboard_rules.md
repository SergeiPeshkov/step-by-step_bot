Правила раскадровки:
- Первый кадр — ритуал (фонарь загорается), 2–3 секунды.
- Последние кадры — Ищущий уходит с фонарём и/или чёрный кадр с тишиной.
- По умолчанию один ключевой видеокадр на ролик, остальные — картинки.
- Типы кадров: image, video, ritual, text, montage, black.
- Текст голоса разбит по кадрам. Пауза 1–2 секунды после главной мысли.
- Медленное движение камеры на картинках (zoom_in / pan), чтобы кадр «жил».
- Общая длина 40–55 секунд, если сцена не короче по плану.
