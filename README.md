# Step-by-Step — бот «По полочкам»

Короткие ролики (40–55 с) о законах и правилах простыми словами.

Telegram-пульт автора: тема → обсуждение ролика с ИИ-сценаристом → сценарий → обсуждение раскадровки → раскадровка и промпты → кадры → озвучка → сборка 9:16 → очередь публикации.

## ИИ-сценарист

Единой формулы ролика нет. После выбора темы бот включает режим «Обсудить ролик»: всё, что вы пишете в чат (текстом или голосом), уходит ИИ-сценаристу, и вы вместе договариваетесь о структуре, тоне и фактах именно этого ролика. Кнопка «Написать сценарий» — ИИ пишет сценарий по итогам обсуждения.

После утверждения сценария с тем же ИИ обсуждаются раскадровка и промпты. Кнопка «Сделать раскадровку и промпты» — ИИ возвращает кадры с готовыми промптами, они уходят в генерацию картинок и видео.

ИИ-сценарист настраивается отдельно в `.env` (`WRITER_*`), например более сильная модель через OpenRouter. Если `WRITER_*` пусты, используется основная модель `LLM_*`. Платная генерация и публикация только после вашей кнопки.

Контент-план **не вшит**. Свой план загружается файлом в `/plan` (CSV или JSON). Шаблон: `data/plan_template.csv`.

## Запуск

1. Скопируйте `.env.example` в `.env`, укажите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_OWNER_ID`.
2. Без ключей ИИ работают заглушки (`*_PROVIDER=stub`): бот проходит весь цикл на плейсхолдерах.
3. Python 3.12, FFmpeg в PATH.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Если `TELEGRAM_OWNER_ID` не указан, бот никому не отвечает и подскажет ваш ID в ответ на любое сообщение.

Музыку с правом использования положите в `data/music/`. Шрифт кириллицы — `data/fonts/DejaVuSans.ttf`.

## Площадки

Каждая площадка включается, когда в `.env` заполнены её строки. Список включённых — в `/settings`.

| Площадка | Как публикуется | Что нужно в `.env` |
|---|---|---|
| Telegram | автоматически | `TELEGRAM_CHANNEL_ID` |
| VK | автоматически | `VK_ACCESS_TOKEN`, `VK_GROUP_ID` |
| YouTube Shorts | автоматически | `YOUTUBE_CLIENT_ID`, `YOUTUBE_CLIENT_SECRET`, `YOUTUBE_REFRESH_TOKEN` (выдаёт `python scripts/youtube_auth.py`) |
| Одноклассники | автоматически | `OK_APP_KEY`, `OK_APP_SECRET`, `OK_ACCESS_TOKEN`, `OK_GROUP_ID` |
| Instagram Reels | автоматически или вручную | `INSTAGRAM_USER_ID`, `INSTAGRAM_ACCESS_TOKEN`; без них `INSTAGRAM_MANUAL=true` |
| Дзен | вручную (открытого API нет) | `DZEN_MANUAL=true` — бот пришлёт файл и текст |

Ссылка на сайт: `SITE_URL`. Если задана, бот сам добавляет в конец ролика карточку «Подробнее — на сайте …» и строку со ссылкой в описание. Пока сайта нет, оставьте пустым.

## Команды

| Команда | Назначение |
|---|---|
| `/new` | Новый ролик: сцена из плана или своя тема |
| `/plan` | План, свободные/занятые сцены, импорт файла |
| `/videos` | Ролики в работе |
| `/queue` | Очередь публикаций |
| `/stats` | Статистика |
| `/costs` | Расходы и лимиты |
| `/facts` | База проверенных фактов |
| `/brain` | Правка «мозга» без кода |
| `/settings` | Провайдеры и лимиты |

Сборка отдельно от бота: `python scripts/assemble.py sheet.json out.mp4`.

Провайдеры — адаптеры в `app/adapters/`. Смена модели: новый адаптер + `.env`, логика бота не меняется.
